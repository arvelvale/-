# 代码修改标记规则

## 核心原则
**立即标记** - 写临时代码时立即标记，不依赖记忆  
**自动维护** - 自动更新TODO清单文件  
**部署前清理** - 部署前必须处理所有TODO项

---

## 1. 必须标记的代码

✅ 模拟数据（Mock数据、测试数据）  
✅ 模拟认证（假Token、测试登录）  
✅ 测试用户（硬编码用户ID）  
✅ 临时配置（开发环境配置）  
✅ Mock服务（模拟第三方服务）  
✅ 调试代码（console.log等）  
✅ 性能问题（已知瓶颈）

---

## 2. 标记格式

### 通用格式
```javascript
// TODO [类型]: <描述>
// 建议: <修改建议>
// 优先级: 高/中/低

代码内容
```

### 标记类型

| 类型 | 标记 | 示例 |
|------|------|------|
| 模拟数据 | `[模拟数据]` | Mock API响应、测试数据 |
| 模拟认证 | `[模拟认证]` | 假Token、测试登录 |
| 测试用户 | `[测试用户]` | 硬编码用户ID |
| 临时配置 | `[临时配置]` | 硬编码API地址 |
| Mock服务 | `[Mock服务]` | 模拟支付、短信 |
| 调试代码 | `[调试代码]` | console.log |
| 性能优化 | `[性能优化]` | 已知瓶颈 |

### 示例

```javascript
// TODO [模拟数据]: 用户列表需替换为真实API
// 建议: 调用 GET /api/users 接口
// 优先级: 高

const mockUsers = [
  { id: 1, name: '测试用户' }
];
```

## 3. TODO清单文件

### 文件：`TODO-修改清单.md`

```markdown
# 代码修改清单

> 最后更新: YYYY-MM-DD

## 统计
- 总计: X项
- 高优先级: X项 🔥
- 中等优先级: X项 ⚡
- 低优先级: X项 💡

## 模拟数据
### 1. [标题]
- 文件: `路径`
- 描述: ...
- 建议: ...
- 优先级: 高/中/低

## 部署前清理
- [ ] 所有调试代码
- [ ] 所有模拟数据
- [ ] 所有Mock服务
```

---

## 4. AI执行流程

### 编写临时代码时
1. 识别临时代码
2. 添加TODO标记
3. 更新TODO清单
4. 同时提交代码和清单

### 完成TODO时
1. 标记完成状态
2. 删除TODO注释
3. 更新统计数据

---

## 5. 优先级判定

| 优先级 | 标记 | 适用场景 |
|--------|------|----------|
| 极高 🔥 | 敏感信息 | 密钥、密码 |
| 高 🔥 | 安全风险 | 模拟认证、严重Bug |
| 中 ⚡ | 正常迭代 | 模拟数据、临时配置 |
| 低 💡 | 可延后 | 调试代码、UI优化 |

---

## 6. 执行检查清单

每次编写临时代码后：
- [ ] 添加规范TODO标记
- [ ] 提供修改建议
- [ ] 设置优先级
- [ ] 更新TODO清单
- [ ] 同时提交代码和清单

---

**记住**：写临时代码时立即标记，永远不要依赖记忆！
