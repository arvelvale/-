# 多Agent心理分析工作流可视化

## 整体流程概览

### 简化版流程图
```
用户写完日记
    ↓
【触发】心理分析工作流
    ↓
┌─────────────────────────────────────────────────────────────┐
│                    LangGraph 状态机                          │
│                                                              │
│  Agent 0 → Agent 1 → Agent 2 → Agent 3                      │
│  (收集)    (提取)    (分析)    (图谱)                        │
└─────────────────────────────────────────────────────────────┘
    ↓
【输出】完整的心理分析报告
```

### 详细数据流图

```
┌──────────────────────────────────────────────────────────────────────┐
│ 用户输入                                                              │
│ ────────────────────────────────────────────────────────────────────│
│ • userId: 123                                                         │

└──────────────────────────────────────────────────────────────────────┘
        │
        ↓

│ ────────────────────────────────────────────────────────────────────│
│ 输入源:                                                               │
│   1️⃣ 用户输入 (userId, diaryId, diaryContent)                       │

│   ✓ 时间轴上下文: 最近7天的事件摘要、情绪、重要性                   │
│   ✓ 相关记忆: 相似的历史日记片段、相似度分数                        │
│   ✓ 图谱上下文: 相关人物、压力触发次数                              │
└──────────────────────────────────────────────────────────────────────┘
        │
        ↓ (传递完整State)
┌──────────────────────────────────────────────────────────────────────┐

│ ────────────────────────────────────────────────────────────────────│
│ 输入源:                                                               │
│   1️⃣ Agent 0 输出的完整State                                        │
│   2️⃣ LLM (用于事件提取)                                             │
│                                                                       │
│ 处理:                                                                 │
│   • 从diaryContent提取关键事件                                       │

│                                                                       │

│   ✓ 当前事件: 事件摘要、情绪标签、重要性评分、事件类型、相关实体    │
│   ✓ 检测到的模式: 连续事件模式、严重程度                            │
│   (保留Agent 0的所有输出)                                            │
└──────────────────────────────────────────────────────────────────────┘
        │
        ↓ (传递State + currentEvent + detectedPatterns)
┌──────────────────────────────────────────────────────────────────────┐
│ Agent 2: 萨提亚分析师 (Satir Therapist)                              │
│ ────────────────────────────────────────────────────────────────────│
│ 输入源:                                                               │
│   1️⃣ Agent 1 输出的完整State (包含所有上下文)                       │
│   2️⃣ LLM (4次调用，每个子节点1次)                                   │
│                                                                       │

│   │ 输入: diaryContent + userProfile + timelineContext      │        │

│        ↓                                                              │

│        ↓                                                              │
│   ┌────────────────────────────────────────────────────────┐        │

│   │ 输入: Node 2.1+2.2输出 + timelineContext                │        │
│   │ 输出: coreSelfLayer                                     │        │
│   └────────────────────────────────────────────────────────┘        │
│        ↓                                                              │
│   ┌────────────────────────────────────────────────────────┐        │
│   │ Node 2.4: 疗愈回信生成器                                │        │
│   │ 输入: 所有层分析结果 + userProfile.personalityType      │        │
│   │ 输出: therapeuticResponse                               │        │
│   └────────────────────────────────────────────────────────┘        │
│                                                                       │
│ 输出内容:                                                             │
│   ✓ 行为层: 事件描述、应对姿态                                       │
│   ✓ 情绪层: 表层情绪、潜在情绪                                       │

│   (保留Agent 0和Agent 1的所有输出)                                   │
└──────────────────────────────────────────────────────────────────────┘
        │
        ↓ (传递State + 五层分析结果)

│ ────────────────────────────────────────────────────────────────────│
│ 输入源:                                                               │
│   1️⃣ Agent 2 输出的完整State (包含所有分析结果)                     │
│   2️⃣ LLM (用于实体关系提取)                                         │
│   3️⃣ Neo4j - 知识图谱 (写入)                                        │
│                                                                       │
│ 处理:                                                                 │
│   • 从currentEvent和分析结果中提取实体                               │
│   • 建立实体关系 (Person-Event-Emotion)                             │
│   • 更新Neo4j图谱                                                    │

│   ✓ 新增关系: 实体之间的关系链接                                     │
│   (保留前面所有Agent的输出)                                          │
└──────────────────────────────────────────────────────────────────────┘
        │
        ↓
┌──────────────────────────────────────────────────────────────────────┐
│ 最终输出: 完整的心理分析报告                                         │
│ ────────────────────────────────────────────────────────────────────│
│                                                                       │
│ 【基础信息】                                                         │
│   • 追踪ID、用户ID、日记ID                                          │
│                                                                       │
│ 【萨提亚五层分析】                                                   │
│   • 行为层: 事件描述、应对姿态                                       │
│   • 情绪层: 表层情绪、潜在情绪                                       │
```

## Agent 0: 上下文收集器 (Context Collector)

### 职责
收集心理分析所需的所有上下文信息，为后续Agent提供完整的输入数据

### 输入
```json
{
  "userId": 123,
  "diaryId": 456,
  "diaryContent": "今天又被老板批评了..."
}
```

### 处理流程

```
┌──────────────────────────────────────────────────────────┐
│ Step 1: 获取用户画像                                      │
│ ────────────────────────────────────────────────────────│
│ 数据源: MySQL - user_profiles 表                         │
│                                                           │
│ 提取信息:                                                 │
│   • identityTag: "职场精英"                              │
│   • currentState: "压力大"                               │
│   • personalityType: "INTJ"                              │
│   • socialStyle: "职场干货风"                            │
│   • catchphrases: ["复盘一下", "干就完了"]               │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ Step 2: 获取时间轴上下文                                  │
│ ────────────────────────────────────────────────────────│
│ 数据源: MySQL - timeline_events 表                       │
│                                                           │
│ 查询条件:                                                 │
│   • user_id = 123                                        │
│   • event_date >= 最近7天                                │
│   • ORDER BY event_date DESC                             │
│                                                           │
│ 获取数据:                                                 │
│   [                                                       │
│     {                                                     │
│       "date": "2026-02-04",                              │
│       "summary": "项目延期，压力很大",                    │
│       "emotion": "焦虑",                                  │
│       "importance": 8                                     │
│     },                                                    │
│     {                                                     │
│       "date": "2026-02-03",                              │
│       "summary": "失眠",                                  │
│       "emotion": "疲惫",                                  │
│       "importance": 6                                     │
│     }                                                     │
│   ]                                                       │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ Step 3: 检索相关历史记忆 (可选)                          │
│ ────────────────────────────────────────────────────────│
│ 数据源: Milvus 向量数据库                                │
│                                                           │
│ 检索策略:                                                 │
│   1. 将当前日记内容向量化                                │
│   2. 在用户的历史日记中检索相似内容                      │
│   3. 返回Top 3相似日记片段                               │
│                                                           │
│ 目的:                                                     │
│   • 发现重复模式（如：每次被批评都有类似反应）          │
│   • 提供历史参考                                          │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ Step 4: 获取知识图谱关系 (可选)                          │
│ ────────────────────────────────────────────────────────│
│ 数据源: Neo4j 图数据库                                   │
│                                                           │
│ 查询示例:                                                 │
│   MATCH (u:User {userId: 123})-[:KNOWS]->(p:Person)     │
│   WHERE p.name CONTAINS "老板"                           │
│   RETURN p                                                │
│                                                           │
│ 获取数据:                                                 │
│   {                                                       │
│     "name": "老王",                                       │
│     "relationship": "IS_BOSS_OF",                        │
│     "stressCount": 12  // 已触发12次压力                │
│   }                                                       │
└──────────────────────────────────────────────────────────┘
```

### 输出
```json
{
  "userId": 123,
  "diaryId": 456,
  "diaryContent": "今天又被老板批评了...",
  "diaryDate": "2026-02-05",
```

## Agent 1: 时间线管家 (Timeline Manager)

### 职责
提取当前日记的关键事件，更新时间轴

### 输入
```json
{
  // 来自 Agent 0 的完整上下文
  "userId": 123,
  "diaryContent": "今天又被老板批评了...",
  "timelineContext": [...]  // 历史时间轴
}
```

### 处理流程

```
┌──────────────────────────────────────────────────────────┐
│ LLM Prompt:                                               │
│ ────────────────────────────────────────────────────────│
│ 你是事件提取专家。                                        │
│                                                           │
│ 日记内容: "今天又被老板批评了..."                        │
│                                                           │
│ 请提取:                                                   │
│ 1. 事件摘要（一句话）                                    │
│ 2. 情绪标签                                               │
│ 3. 重要性评分（1-10）                                    │
│ 4. 事件类型（work/relationship/health/achievement）      │
│ 5. 相关实体（人物/地点）                                 │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ LLM 输出:                                                 │
│ ────────────────────────────────────────────────────────│
│ {                                                         │
│   "summary": "被老板批评",                               │
│   "emotionTag": "委屈",                                   │
│   "importanceScore": 8,                                   │
│   "eventType": "work",                                    │
│   "entities": {                                           │
│     "persons": ["老板"],                                 │
│     "locations": ["公司"]                                │
│   }                                                       │
│ }                                                         │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ 模式检测:                                                 │
│ ────────────────────────────────────────────────────────│
│ 分析历史时间轴，检测连续事件:                            │
│                                                           │
│ IF 最近3天都出现"失眠"                                   │
│ THEN 标记为连续模式                                       │
│                                                           │
│ 检测结果:                                                 │
│ {                                                         │
│   "pattern": "连续3天失眠",                              │
│   "severity": "high"                                      │
│ }                                                         │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ 存入数据库:                                               │
│ ────────────────────────────────────────────────────────│
│ INSERT INTO timeline_events (                            │
│   user_id, diary_id, event_date,                         │
│   event_summary, emotion_tag, importance_score           │
│ ) VALUES (...)                                            │
└──────────────────────────────────────────────────────────┘
```

### 输出
```json
{
  // 继承所有输入
  "currentEvent": {
    "summary": "被老板批评",
    "emotionTag": "委屈",
    "importanceScore": 8,
    "eventType": "work",
    "entities": {
      "persons": ["老板"],
      "locations": ["公司"]
    }
  },
  "detectedPatterns": [
    {
      "pattern": "连续3天失眠",
      "severity": "high"
    }
  ]
}
```

## Agent 2: 萨提亚分析师 (Satir Therapist)

### 职责
基于萨提亚冰山模型进行五层深度分析

### 输入
```json
{
  // 来自前面Agent的完整上下文
  "diaryContent": "今天又被老板批评了...",
  "userProfile": {...},
  "timelineContext": [...],
  "currentEvent": {...}
}
```

### 处理流程（5个子节点）

```
┌─────────────────────────────────────────────────────────────┐
│ Node 2.1: 情绪侦探 (Emotion Agent)                          │
│ ═══════════════════════════════════════════════════════════│
│                                                              │
│ LLM Prompt:                                                  │
│ ────────────────────────────────────────────────────────── │
│ 你是情绪分析师。                                             │
│                                                              │
│ 日记: "今天又被老板批评了..."                               │
│                                                              │
│ 请分析:                                                      │
│ 1. 显性事件（Who/What/Where/When）                         │
│ 2. 应对姿态（指责/讨好/超理智/打岔）                        │
│ 3. 表层情绪（如：愤怒）                                     │
│ 4. 潜在情绪（如：恐惧、委屈）                               │
│                                                              │
│ ────────────────────────────────────────────────────────── │
│ LLM 输出:                                                    │
│ {                                                            │
│   "behaviorLayer": {                                         │
│     "event": "被老板批评",                                  │
│     "copingStyle": "讨好"  // 可能想讨好老板                │
│   },                                                         │
│   "emotionLayer": {                                          │
│     "surface": "愤怒",                                       │
│     "underlying": "恐惧、委屈"                              │
│   }                                                          │
│ }                                                            │
└─────────────────────────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────────────────────────┐
│ Node 2.2: 信念挖掘机 (Cognitive Agent)                      │
│ ═══════════════════════════════════════════════════════════│
│                                                              │
│ LLM Prompt:                                                  │
│ ────────────────────────────────────────────────────────── │
│ 你是认知心理学专家。                                         │
│                                                              │
│ 日记: "今天又被老板批评了..."                               │
│ 情绪分析: {surface: "愤怒", underlying: "恐惧、委屈"}       │
│                                                              │
│ 请分析:                                                      │
│ 1. 非理性信念（如："我必须完美"）                          │
│ 2. 未被满足的期待（如："希望被认可"）                      │
│ 3. 核心价值观（如："成就感很重要"）                        │
│                                                              │
│ ────────────────────────────────────────────────────────── │
│ LLM 输出:                                                    │
│ {                                                            │
│   "cognitiveLayer": {                                        │
│     "thinking": "我必须让所有人满意，否则就是失败"          │
│   },                                                         │
│   "beliefLayer": {                                           │
│     "belief": "成就感来自外部认可，而非内在价值"            │
│   }                                                          │
│ }                                                            │
└─────────────────────────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────────────────────────┐
│ Node 2.3: 灵魂摆渡人 (Existence Agent)                      │
│ ═══════════════════════════════════════════════════════════│
│                                                              │
│ LLM Prompt:                                                  │
│ ────────────────────────────────────────────────────────── │
│ 你是资深萨提亚咨询师。                                       │
│                                                              │
```

## Agent 3: 知识图谱构建器 (Graph Builder)

### 职责
将分析结果写入知识图谱，建立实体关系

### 输入
```json
{
  // 来自前面Agent的完整分析结果
  "currentEvent": {...},
  "behaviorLayer": {...},
  "emotionLayer": {...}
}
```

### 处理流程

```
┌──────────────────────────────────────────────────────────┐
│ Step 1: 提取实体                                          │
│ ────────────────────────────────────────────────────────│
│ 从日记和分析结果中提取:                                  │
│   • Person: "老板"                                       │
│   • Event: "被批评"                                      │
│   • Emotion: "委屈"（强度: 8）                           │
│   • Location: "公司"                                     │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ Step 2: 建立关系                                          │
│ ────────────────────────────────────────────────────────│
│ Cypher 查询:                                              │
│                                                           │
│ // 创建或更新人物节点                                    │
│ MERGE (p:Person {name: "老板"})                          │
│ ON CREATE SET p.firstMentioned = date()                  │
│ ON MATCH SET p.mentionCount = p.mentionCount + 1         │
│                                                           │
│ // 创建事件节点                                           │
│ CREATE (e:Event {                                         │
│   summary: "被批评",                                     │
│   date: date(),                                           │
│   emotion: "委屈"                                         │
│ })                                                        │
│                                                           │
│ // 建立关系                                               │
│ MATCH (u:User {userId: 123})                             │
│ MATCH (p:Person {name: "老板"})                          │
│ CREATE (u)-[:EXPERIENCED]->(e)                           │
│ CREATE (e)-[:CAUSED_BY]->(p)                             │
│ CREATE (e)-[:TRIGGERED]->(em:Emotion {                   │
│   type: "委屈",                                           │
│   intensity: 8                                            │
│ })                                                        │
│                                                           │
│ // 推理关系                                               │
│ MERGE (p)-[:IS_BOSS_OF]->(u)                             │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ Step 3: 更新压力源统计                                    │
│ ────────────────────────────────────────────────────────│
│ MATCH (p:Person {name: "老板"})-[:CAUSED_BY]-(e:Event)  │
│       -[:TRIGGERED]->(em:Emotion {type: "压力"})         │
│ SET p.stressCount = COUNT(e)                             │
│                                                           │
│ 结果: 老板.stressCount = 13 (从12增加到13)               │
└──────────────────────────────────────────────────────────┘
```

### 输出
```json
{
  // 继承所有输入
  "graphUpdated": true,
  "newEntities": ["老板", "被批评事件"],
  "newRelations": ["老板 IS_BOSS_OF 用户", "事件 TRIGGERED 委屈"]
}
```

## 错误处理策略

```
IF Agent 0 失败（无法获取上下文）
  THEN 使用默认用户画像 + 空时间轴
  CONTINUE 流程

IF Agent 1 失败（事件提取失败）
  THEN 跳过时间轴更新
  CONTINUE 流程

IF Agent 2.x 任一节点失败
  THEN 降级为简化版3层分析
  OR 使用通用模板回复

IF Agent 3 失败（图谱更新失败）
  THEN 记录日志
  不影响用户体验（图谱是辅助功能）
```

## 关键设计决策

### 为什么需要Agent 0？
❌ **错误设计**: 每个Agent自己去查数据库
- 导致重复查询（每个Agent都查用户画像）
- 数据不一致（查询时间不同）
- 性能浪费

✅ **正确设计**: Agent 0统一收集上下文
- 一次性收集所有需要的数据
- 保证数据一致性
- 后续Agent只需要读取State

### 为什么Agent 2有4个子节点？
萨提亚冰山模型是**层层递进**的：
1. 先看表面（行为、情绪）
2. 再挖深层（思维、信念）
3. 最后触及核心（存在、渴望）
4. 基于理解生成回复

如果一次性分析，LLM容易：
- 遗漏某些层次
- 分析不够深入
- 逻辑跳跃

### 为什么Agent 3放在最后？
知识图谱更新是**辅助功能**：
- 不影响用户体验（用户不关心图谱）
- 可以异步执行
- 失败了也不影响心理分析结果

如果放在前面，图谱更新失败会阻塞整个流程。
