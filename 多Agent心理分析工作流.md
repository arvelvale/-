# 多Agent心理分析工作流可视化

## 整体流程概览

```
用户写完日记
    ↓
【触发】心理分析工作流
    ↓
┌─────────────────────────────────────────────────────────────┐
│                    LangGraph 状态机                          │
│                                                              │
│  Agent 0: 上下文收集器 (Context Collector)                  │
│         ↓                                                    │
│  Agent 1: 时间线管家 (Timeline Manager)                     │
│         ↓                                                    │
│  Agent 2: 萨提亚分析师 (Satir Therapist)                    │
│         ├─→ Node 2.1: 情绪侦探                              │
│         ├─→ Node 2.2: 信念挖掘机                            │
│         ├─→ Node 2.3: 灵魂摆渡人                            │
│         └─→ Node 2.4: 疗愈回信生成器                        │
│         ↓                                                    │
│  Agent 3: 知识图谱构建器 (Graph Builder)                    │
│         ↓                                                    │
│  【输出】完整的心理分析报告                                  │
└─────────────────────────────────────────────────────────────┘
```

---

## Agent 0: 上下文收集器 (Context Collector)

### 职责
收集心理分析所需的所有上下文信息，为后续Agent提供完整的输入数据

### 输入
```json
{
  "userId": 123,
  "diaryId": 456,
  "diaryContent": "今天又被老板批评了..."
}
```

### 处理流程

```
┌──────────────────────────────────────────────────────────┐
│ Step 1: 获取用户画像                                      │
│ ────────────────────────────────────────────────────────│
│ 数据源: MySQL - user_profiles 表                         │
│                                                           │
│ 提取信息:                                                 │
│   • identityTag: "职场精英"                              │
│   • currentState: "压力大"                               │
│   • personalityType: "INTJ"                              │
│   • socialStyle: "职场干货风"                            │
│   • catchphrases: ["复盘一下", "干就完了"]               │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ Step 2: 获取时间轴上下文                                  │
│ ────────────────────────────────────────────────────────│
│ 数据源: MySQL - timeline_events 表                       │
│                                                           │
│ 查询条件:                                                 │
│   • user_id = 123                                        │
│   • event_date >= 最近7天                                │
│   • ORDER BY event_date DESC                             │
│                                                           │
│ 获取数据:                                                 │
│   [                                                       │
│     {                                                     │
│       "date": "2026-02-04",                              │
│       "summary": "项目延期，压力很大",                    │
│       "emotion": "焦虑",                                  │
│       "importance": 8                                     │
│     },                                                    │
│     {                                                     │
│       "date": "2026-02-03",                              │
│       "summary": "失眠",                                  │
│       "emotion": "疲惫",                                  │
│       "importance": 6                                     │
│     }                                                     │
│   ]                                                       │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ Step 3: 检索相关历史记忆 (可选)                          │
│ ────────────────────────────────────────────────────────│
│ 数据源: Milvus 向量数据库                                │
│                                                           │
│ 检索策略:                                                 │
│   1. 将当前日记内容向量化                                │
│   2. 在用户的历史日记中检索相似内容                      │
│   3. 返回Top 3相似日记片段                               │
│                                                           │
│ 目的:                                                     │
│   • 发现重复模式（如：每次被批评都有类似反应）          │
│   • 提供历史参考                                          │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ Step 4: 获取知识图谱关系 (可选)                          │
│ ────────────────────────────────────────────────────────│
│ 数据源: Neo4j 图数据库                                   │
│                                                           │
│ 查询示例:                                                 │
│   MATCH (u:User {userId: 123})-[:KNOWS]->(p:Person)     │
│   WHERE p.name CONTAINS "老板"                           │
│   RETURN p                                                │
│                                                           │
│ 获取数据:                                                 │
│   {                                                       │
│     "name": "老王",                                       │
│     "relationship": "IS_BOSS_OF",                        │
│     "stressCount": 12  // 已触发12次压力                │
│   }                                                       │
└──────────────────────────────────────────────────────────┘
```

### 输出
```json
{
  "userId": 123,
  "diaryId": 456,
  "diaryContent": "今天又被老板批评了...",
  "diaryDate": "2026-02-05",
  
  "userProfile": {
    "identityTag": "职场精英",

      "importance": 8
    },
    {
      "date": "2026-02-03",
      "summary": "失眠",
```

## Agent 1: 时间线管家 (Timeline Manager)

### 职责
提取当前日记的关键事件，更新时间轴

### 输入
```json
{
  // 来自 Agent 0 的完整上下文
  "userId": 123,
  "diaryContent": "今天又被老板批评了...",
  "timelineContext": [...]  // 历史时间轴
}
```

### 处理流程

```
┌──────────────────────────────────────────────────────────┐
│ LLM Prompt:                                               │
│ ────────────────────────────────────────────────────────│
│ 你是事件提取专家。                                        │
│                                                           │
│ 日记内容: "今天又被老板批评了..."                        │
│                                                           │
│ 请提取:                                                   │
│ 1. 事件摘要（一句话）                                    │
│ 2. 情绪标签                                               │
│ 3. 重要性评分（1-10）                                    │
│ 4. 事件类型（work/relationship/health/achievement）      │
│ 5. 相关实体（人物/地点）                                 │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ LLM 输出:                                                 │
│ ────────────────────────────────────────────────────────│
│ {                                                         │
│   "summary": "被老板批评",                               │
│   "emotionTag": "委屈",                                   │
│   "importanceScore": 8,                                   │
│   "eventType": "work",                                    │
│   "entities": {                                           │
│     "persons": ["老板"],                                 │
│     "locations": ["公司"]                                │
│   }                                                       │
│ }                                                         │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ 模式检测:                                                 │
│ ────────────────────────────────────────────────────────│
│ 分析历史时间轴，检测连续事件:                            │
│                                                           │
│ IF 最近3天都出现"失眠"                                   │
│ THEN 标记为连续模式                                       │
│                                                           │
│ 检测结果:                                                 │
│ {                                                         │
│   "pattern": "连续3天失眠",                              │
│   "severity": "high"                                      │
│ }                                                         │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ 存入数据库:                                               │
│ ────────────────────────────────────────────────────────│
│ INSERT INTO timeline_events (                            │
│   user_id, diary_id, event_date,                         │
│   event_summary, emotion_tag, importance_score           │
│ ) VALUES (...)                                            │
└──────────────────────────────────────────────────────────┘
```

### 输出
```json
{
  // 继承所有输入
  "currentEvent": {
    "summary": "被老板批评",
    "emotionTag": "委屈",
    "importanceScore": 8,
    "eventType": "work",
    "entities": {
      "persons": ["老板"],
      "locations": ["公司"]
    }
  },
  "detectedPatterns": [
    {
      "pattern": "连续3天失眠",
      "severity": "high"
    }
  ]
}
```

## Agent 2: 萨提亚分析师 (Satir Therapist)

### 职责
基于萨提亚冰山模型进行五层深度分析

### 输入
```json
{
  // 来自前面Agent的完整上下文
  "diaryContent": "今天又被老板批评了...",
  "userProfile": {...},
  "timelineContext": [...],
  "currentEvent": {...}
}
```

### 处理流程（5个子节点）

```
┌─────────────────────────────────────────────────────────────┐
│ Node 2.1: 情绪侦探 (Emotion Agent)                          │
│ ═══════════════════════════════════════════════════════════│
│                                                              │
│ LLM Prompt:                                                  │
│ ────────────────────────────────────────────────────────── │
│ 你是情绪分析师。                                             │
│                                                              │
│ 日记: "今天又被老板批评了..."                               │
│                                                              │
│ 请分析:                                                      │
│ 1. 显性事件（Who/What/Where/When）                         │
│ 2. 应对姿态（指责/讨好/超理智/打岔）                        │
│ 3. 表层情绪（如：愤怒）                                     │
│ 4. 潜在情绪（如：恐惧、委屈）                               │
│                                                              │
│ ────────────────────────────────────────────────────────── │
│ LLM 输出:                                                    │
│ {                                                            │
│   "behaviorLayer": {                                         │
│     "event": "被老板批评",                                  │
│     "copingStyle": "讨好"  // 可能想讨好老板                │
│   },                                                         │
│   "emotionLayer": {                                          │
│     "surface": "愤怒",                                       │
│     "underlying": "恐惧、委屈"                              │
│   }                                                          │
│ }                                                            │
└─────────────────────────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────────────────────────┐
│ Node 2.2: 信念挖掘机 (Cognitive Agent)                      │
│ ═══════════════════════════════════════════════════════════│
│                                                              │
│ LLM Prompt:                                                  │
│ ────────────────────────────────────────────────────────── │
│ 你是认知心理学专家。                                         │
│                                                              │
│ 日记: "今天又被老板批评了..."                               │
│ 情绪分析: {surface: "愤怒", underlying: "恐惧、委屈"}       │
│                                                              │
│ 请分析:                                                      │
│ 1. 非理性信念（如："我必须完美"）                          │
│ 2. 未被满足的期待（如："希望被认可"）                      │
│ 3. 核心价值观（如："成就感很重要"）                        │
│                                                              │
│ ────────────────────────────────────────────────────────── │
│ LLM 输出:                                                    │
│ {                                                            │
│   "cognitiveLayer": {                                        │
│     "thinking": "我必须让所有人满意，否则就是失败"          │
│   },                                                         │
│   "beliefLayer": {                                           │
│     "belief": "成就感来自外部认可，而非内在价值"            │
│   }                                                          │
│ }                                                            │
└─────────────────────────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────────────────────────┐
│ Node 2.3: 灵魂摆渡人 (Existence Agent)                      │
│ ═══════════════════════════════════════════════════════════│
│                                                              │
│ LLM Prompt:                                                  │
│ ────────────────────────────────────────────────────────── │
│ 你是资深萨提亚咨询师。                                       │
│                                                              │
│ 用户行为: {event: "被老板批评", copingStyle: "讨好"}        │
│ 情绪: {surface: "愤怒", underlying: "恐惧、委屈"}           │
│ 思维: "我必须让所有人满意"                                  │
│ 信念: "成就感来自外部认可"                                  │
│ 历史背景: [连续3天失眠, 项目延期...]                        │
│                                                              │
│ 请洞察深层渴望:                                              │
│ - 被爱（Love）                                              │
│ - 被接纳（Acceptance）                                      │
│ - 自由（Freedom）                                           │
│ - 意义（Meaning）                                           │
│                                                              │
│ ────────────────────────────────────────────────────────── │
│ LLM 输出:                                                    │
│ {                                                            │
│   "coreSelfLayer": {                                         │
│     "desire": "被接纳、被认可",                             │
│     "lifeEnergy": "你内心深处渴望被看见、被肯定。           │
│                    这份渴望驱使你不断证明自己的价值，        │
│                    但也让你忽略了自己本身就足够好。"         │
│   }                                                          │
│ }                                                            │
└─────────────────────────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────────────────────────┐
│ Node 2.4: 疗愈回信生成器 (Therapeutic Responder)            │
│ ═══════════════════════════════════════════════════════════│
│                                                              │
│ LLM Prompt:                                                  │
│ ────────────────────────────────────────────────────────── │
│ 你是温暖的心理陪伴者。                                       │
│                                                              │
│ 用户深层分析: {desire: "被接纳、被认可", ...}               │
│ 用户性格: INTJ                                               │
│ 回复语气: 理性分析，提供框架                                │
│                                                              │
│ 请生成温暖回复（200-300字），包含:                          │
│ 1. 看见他的感受                                              │
│ 2. 连接到他的渴望                                            │
│ 3. 给予具体的成长建议                                        │
│                                                              │
│ ────────────────────────────────────────────────────────── │
│ LLM 输出:                                                    │
│ {                                                            │
│   "therapeuticResponse": "我看到了你的委屈和恐惧。          │
│   被批评确实让人难受，但这不代表你不够好。                  │
│   你内心深处渴望被认可，这很正常。                          │
│   但请记住，你的价值不需要通过他人的评价来证明。            │
│   建议：                                                     │
│   1. 区分事实和情绪（批评≠否定你这个人）                   │
│   2. 建立内在评价体系（我做得如何？而非他人怎么看）        │
│   3. 练习自我肯定（每天写下3件做得好的事）"                │
│ }                                                            │
└─────────────────────────────────────────────────────────────┘
```

### 输出
```json
{
  // 继承所有输入
  "behaviorLayer": {...},
  "emotionLayer": {...},
  "cognitiveLayer": {...},
  "beliefLayer": {...},
  "coreSelfLayer": {...},
  "therapeuticResponse": "我看到了你的委屈和恐惧..."
}
```

## Agent 3: 知识图谱构建器 (Graph Builder)

### 职责
将分析结果写入知识图谱，建立实体关系

### 输入
```json
{
  // 来自前面Agent的完整分析结果
  "currentEvent": {...},
  "behaviorLayer": {...},
  "emotionLayer": {...}
}
```

### 处理流程

```
┌──────────────────────────────────────────────────────────┐
│ Step 1: 提取实体                                          │
│ ────────────────────────────────────────────────────────│
│ 从日记和分析结果中提取:                                  │
│   • Person: "老板"                                       │
│   • Event: "被批评"                                      │
│   • Emotion: "委屈"（强度: 8）                           │
│   • Location: "公司"                                     │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ Step 2: 建立关系                                          │
│ ────────────────────────────────────────────────────────│
│ Cypher 查询:                                              │
│                                                           │
│ // 创建或更新人物节点                                    │
│ MERGE (p:Person {name: "老板"})                          │
│ ON CREATE SET p.firstMentioned = date()                  │
│ ON MATCH SET p.mentionCount = p.mentionCount + 1         │
│                                                           │
│ // 创建事件节点                                           │
│ CREATE (e:Event {                                         │
│   summary: "被批评",                                     │
│   date: date(),                                           │
│   emotion: "委屈"                                         │
│ })                                                        │
│                                                           │
│ // 建立关系                                               │
│ MATCH (u:User {userId: 123})                             │
│ MATCH (p:Person {name: "老板"})                          │
│ CREATE (u)-[:EXPERIENCED]->(e)                           │
│ CREATE (e)-[:CAUSED_BY]->(p)                             │
│ CREATE (e)-[:TRIGGERED]->(em:Emotion {                   │
│   type: "委屈",                                           │
│   intensity: 8                                            │
│ })                                                        │
│                                                           │
│ // 推理关系                                               │
│ MERGE (p)-[:IS_BOSS_OF]->(u)                             │
└──────────────────────────────────────────────────────────┘
        ↓
┌──────────────────────────────────────────────────────────┐
│ Step 3: 更新压力源统计                                    │
│ ────────────────────────────────────────────────────────│
│ MATCH (p:Person {name: "老板"})-[:CAUSED_BY]-(e:Event)  │
│       -[:TRIGGERED]->(em:Emotion {type: "压力"})         │
│ SET p.stressCount = COUNT(e)                             │
│                                                           │
│ 结果: 老板.stressCount = 13 (从12增加到13)               │
└──────────────────────────────────────────────────────────┘
```

### 输出
```json
{
  // 继承所有输入
  "graphUpdated": true,
  "newEntities": ["老板", "被批评事件"],
  "newRelations": ["老板 IS_BOSS_OF 用户", "事件 TRIGGERED 委屈"]
}
```

## 完整数据流

```
┌─────────────────────────────────────────────────────────────┐
│ 输入: 用户写完日记                                          │
│ {                                                            │
│   "userId": 123,                                             │
│   "diaryId": 456,                                            │
│   "diaryContent": "今天又被老板批评了..."                   │
│ }                                                            │
└─────────────────────────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────────────────────────┐
│ Agent 0: 上下文收集器                                        │
│ ─────────────────────────────────────────────────────────── │
│ 收集:                                                        │
│   ✓ 用户画像 (MySQL)                                        │
│   ✓ 时间轴上下文 (MySQL)                                    │
│   ✓ 相关记忆 (Milvus)                                       │
│   ✓ 图谱关系 (Neo4j)                                        │
│                                                              │
│ 输出: 完整上下文 State                                       │
└─────────────────────────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────────────────────────┐
│ Agent 1: 时间线管家                                          │
│ ─────────────────────────────────────────────────────────── │
│ 处理:                                                        │
│   ✓ 提取关键事件                                            │
│   ✓ 检测连续模式                                            │
│   ✓ 更新时间轴 (MySQL)                                      │
│                                                              │
│ 输出: State + currentEvent + detectedPatterns               │
└─────────────────────────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────────────────────────┐
│ Agent 2: 萨提亚分析师 (5个子节点顺序执行)                   │
│ ─────────────────────────────────────────────────────────── │
│ Node 2.1: 情绪侦探                                           │
│   ✓ 分析行为层和情绪层                                      │
│   ↓                                                          │
│ Node 2.2: 信念挖掘机                                         │
│   ✓ 分析思维层和信念层                                      │
│   ↓                                                          │
│ Node 2.3: 灵魂摆渡人                                         │
│   ✓ 洞察存在层（深层渴望）                                  │
│   ↓                                                          │
│ Node 2.4: 疗愈回信生成器                                     │
│   ✓ 生成温暖的疗愈回复                                      │
│                                                              │
│ 输出: State + 五层分析 + therapeuticResponse                │
└─────────────────────────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────────────────────────┐
│ Agent 3: 知识图谱构建器                                      │
│ ─────────────────────────────────────────────────────────── │
│ 处理:                                                        │
│   ✓ 提取实体和关系                                          │
│   ✓ 更新Neo4j图谱                                           │
│   ✓ 推理隐含关系                                            │
│                                                              │
│ 输出: State + graphUpdated                                  │
└─────────────────────────────────────────────────────────────┘
```

## 错误处理策略

```
IF Agent 0 失败（无法获取上下文）
  THEN 使用默认用户画像 + 空时间轴
  CONTINUE 流程

IF Agent 1 失败（事件提取失败）
  THEN 跳过时间轴更新
  CONTINUE 流程

IF Agent 2.x 任一节点失败
  THEN 降级为简化版3层分析
  OR 使用通用模板回复

IF Agent 3 失败（图谱更新失败）
  THEN 记录日志
  不影响用户体验（图谱是辅助功能）
```
